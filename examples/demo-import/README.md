# Imagens locais de demonstração

Estes arquivos são ilustrações geométricas sintéticas criadas para validar a importação. Não contêm páginas de mangá, nomes de pessoas ou dados de terceiros.

No aplicativo, abra **Importar imagens**, selecione a pasta `pasta` ou `demo.cbz`, revise a ordem, informe um título de mangá/capítulo de demonstração e confirme que tem autorização para processar estes arquivos. A pasta `pagina-dupla` contém uma composição panorâmica geométrica para testar divisão RTL/LTR. A importação grava somente no perfil local.
